# SurrealKB 登录跳板小程序

只干一件事：**被电脑网页的二维码扫进来 → 把登录票据交给后端 → 网页完成登录**。
不需要任何页面设计、不认证、不发布到搜索，纯登录中转。

## 为什么用小程序而不是微信网站应用

微信开放平台「网站应用」扫码登录要求**企业/个体工商户营业执照 + 300 元认证 + 已备案域名**，
个人主体在后台里根本没有申请入口。小程序**个人实名即可注册、0 元**，是个人开发者的唯一正规解。

## 使用步骤（详见项目根目录的配置指南）

1. 去 [微信公众平台](https://mp.weixin.qq.com/) 注册**个人小程序**（实名 + 微信扫码验证，0 元）
2. 小程序后台 →「开发 → 开发管理 → 开发设置」拿到 **AppID / AppSecret**，填到后端 `backend/.env`：
   ```
   WX_MP_APP_ID=wx..........
   WX_MP_APP_SECRET=..........
   ```
3. 改本目录 `config.js` 里的 `API_BASE` 为你的后端地址（必须 https）
4. 用[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)导入本目录
   （`project.config.json` 里的 `appid` 换成你自己的；或导入时选「测试号」）
5. 上传 → 提交审核 → 发布（**必须发布**，`getwxacodeunlimit` 生成的码指向正式版）
6. 小程序后台配好 **request 合法域名**（= 你的后端域名，要求已备案）

## 本地调试（不用真机扫码）

微信开发者工具 →「普通编译」下拉 →「添加编译模式」：

| 字段 | 填 |
|---|---|
| 启动页面 | `pages/login/index` |
| 启动参数 | `scene=任意32位字符串` |

这样就能模拟「扫码进来」的效果，配合后端 `/api/auth/wx/qrcode` 返回的真实票据即可全链路自测。

## 两个必须知道的坑

- **`scene` 必须是全局唯一随机值**：重复会导致两个用户登录进同一个账号。后端已用
  `secrets.token_hex(16)` 生成（正好 32 字符，卡在微信上限）。
- **域名白名单**：小程序 `wx.request` 的域名必须 https 且已备案。
  若还没备案，可用微信云开发的云函数做中转（云函数在服务端发起请求，不受该白名单约束）。
